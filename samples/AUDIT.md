讀檔追加驗證：前一輪直接建立 world 未涵蓋計畫時間軸初始化，漏掉 PDF 站前／站後折返讀檔錯誤。已修正停車保護遺失 cursor 問題，並逐檔執行實際 `ConfigureTopologyProjectForPlayback`；12 個現行範例及六站預設全部通過計畫時間軸、速度預覽與畫面初始化。完整回歸現為 120/120；未操作桌面檔案選擇對話框。

範圍是 12 個現行 JSON 範例，另檢查 MainWindow 啟動時的六站預設。逐份核對站型與名稱、上下行進路、月台及車長、設施引用、派車接續，再以實際 world 推進 3,600 秒。主畫面與編輯器均以 WPF 繪圖程式產生 720／1200 px 圖像；這是程式內驗證，並非桌面手動操作驗收。

所有上述情境在 3,600 秒時均為零運行中列車、零碰撞、零停站違規。中間站袋狀軌作業會產生有界的反向車次，因此有兩檔的實際方向別車次數大於派車列數，並非無限派車。

舊檔名保留以相容既有連結；專案畫面名稱與本表使用實際配置。真正的雙島四股請使用 PDF-DoubleIslandFourTracks。

普通／快速車有不同車長的舊範例，仍以 VehicleTypes 的各車型長度為運行權威；全域 operations.trainLengthMeters 是相容預設，沒有將普通車改成快速車車長。PDF 的尺寸、性能、停站及班次也都是示範值，未當作 PDF 提供的工程數據。

驗證：Release build 0 警告／0 錯誤，完整 tests 119/119 通過。新增共用節點禁止轉向的 graph-distance regression，並擴充 Schema 7 轉換測試，驗證簡易班距與手動班表的雙向起站均取自進路第一停點。

本輪未重做桌面手動讀檔／儲存／參數對話框／匯出流程。動態圖像以 90 秒快照為主，完整運行安全性由事件與最終狀態確認，不代表逐幀人工視覺驗收。
