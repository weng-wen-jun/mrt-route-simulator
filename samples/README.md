# V3.3.0 完整功能驗證範例

範例檔：`V3.3.0-完整功能驗證範例.mrtsim.json`

這是一份 Schema 7 合成測試資料，用來一次檢查 V3.3 的專案讀取、即時路線圖、雙向派車、停站秒數覆寫、停站／跨站、指定車次接續、端點退出、車型性能、移動閉塞、速度曲線、時刻表、區間統計及五類 URCS 空間參考點。數值不是任何真實路線的設計或安全依據。

`archive/` 只保存歷史 V3.2 範例供比對；現行程式會依內部測試政策拒絕其舊 Schema，不應拿來做 V3.3 驗收。

## 操作方式

1. 啟動 `MRT路線進出站時間模擬器.exe`。
2. 選「檔案 → 讀取存檔」，載入本範例檔。
3. 讀取完成後，首頁路線圖應立即改為五站驗證線，並顯示五個空間參考點；這一步不必先建立模擬。
4. 按動畫頁上方常駐的「建立模擬【V3.3】」。
5. 以 `20×` 播放。要看到指定接續車次，至少播放到模擬時鐘 `06:12:00`；完整檢查可播放到約 `06:40:00`。
6. 逐頁查看進出站時刻表、區間物理、移動閉塞與煞車、V2 區間統計、下行速度曲線及列車運行圖。

## 主要情境與預期結果

| 驗證項目 | 範例設定 | 預期結果 |
|---|---|---|
| 五類空間參考點 | V01 站前折返、V02 中間站、V03 銜接點、V04 中央避車線折返、V05 站後折返 | 讀檔後立即出現在首頁路線圖；容量提示與各類參數可在空間參考點設定中檢查 |
| 中間站方向獨立 | V02 下行停站 42 秒、上行停站 11 秒 | 上下行抵達 V02 後的停站時間不同 |
| 指定反向接續 | `EMU-CIRC-01` 的 `RUN-DOWN-001` 指定接續 `RUN-UP-006` | 同一實體 `VehicleId` 於 V05 折返，在 06:12 以指定上行車次發車，不另生成一列車 |
| 端點退出 | `EMU-EXIT-U01`、`EMU-EXP-D02`、`EMU-EXP-U02`、`EMU-EXIT-D03` 均不續行 | 完成端點停站／清車後產生「退出營運」，車輛從路線圖及安全配對消失 |
| 普通／快速停站模式 | 普通車全停；快速車跨越 V02、V04 | 快速車產生跨站事件，速度曲線不中斷為停站 |
| 雙方向派車 | 06:00 起依手動班表由 V01、V05 兩端發車 | 路線圖、時刻表、運行圖及軌跡同時包含上行與下行 |
| 車型與服務類型 | EMU-6／EMU-8；普通車／快速車 | 車次、速度曲線及結果列保留車型、服務類型與停站模式識別 |
| 方向別里程速限 | 雙向 55 km/h、下行 45 km/h、上行 50 km/h | 實際速度曲線在對應方向與里程受限，提前煞車事件可在軌跡中觀察 |
| 月台、軌道與進路 | 雙向主線、V03 避車線、逐區間進路與資源 | 事件包含月台配置、進路預約／釋放；移動閉塞頁產生安全距離歷程 |
| 結果頁 | V2 寫實引擎事件與軌跡 | 時刻表可見「折返接續／退出營運」；V3.3 區間統計含完整篩選與閉塞受限秒數；上下行速度／運行圖均有資料 |
