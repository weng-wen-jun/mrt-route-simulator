# 路線圖垂直配置

在「專案工作區 → 軌道與設施 → 垂直配置」調整。

- 圖面中線為 0。上行主線為 −1、下行主線為 +1，主線基準固定。
- 每單位為 23 DIP；上下行主線相隔 2 單位，即 46 DIP。DIP 是 WPF 邏輯像素，這些數值不表示實體軌道間距。
- 支線預設向 +2、+3 等正值遞增，水平區段重疊時分配不同單位；不重疊的支線可以重用同一單位。
- 正值向下、負值向上。支線可輸入 −8 至 +8 的有限數值，包含小數；留空使用自動配置。
- 「套用預設垂直配置」重設主線基準與側線配置。既有手動支線配置在一般預覽時保留。
- 「預覽配線」查看調整後的軌道與月台；返回「軌道與設施」可繼續調整。
- 按工作區的「套用」，再儲存專案，垂直位置隨 Schema 8 專案保存。「取消」不修改原專案。

主圖與編輯器使用同一個單位映射。大型路線不再壓縮側線的垂直單位；接軌轉向段仍連續接回主線。軌道、月台與列車共用 edge-local 位置映射，此設定不改變列車速度、實體長度、port-side 或有向接續。

快速通過正線可能不在預設全停路徑內，因此會從相鄰的有向主線接續繼承方向基準。超過 +8 的密集支線不能由預設按鈕自動排開，需手動調整；自動預覽仍可顯示專案。

    dotnet run --project tests/MrtRouteSimulator.WpfTests/MrtRouteSimulator.WpfTests.csproj -c Release --no-build --no-restore -- D:\AI\codex\mrt-route-simulator --vertical-lanes-only
