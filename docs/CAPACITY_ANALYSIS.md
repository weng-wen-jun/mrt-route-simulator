# 容量參考點計算

此功能計算手動配置參考點的局部理論容量，與「資源占用與觀測容量」的實際模擬統計分開。使用者需要提供號誌重疊區、巡航速度、安全係數、停等時間、列車性能及乘位等規劃假設；程式不從路線圖或 topology 自動猜測。

## 操作與保存

在「容量參考點」頁開啟設定，選擇計算基準、填寫全域與列車參數，再新增中間站、站前折返、站後折返、中央避車線或銜接點。中間站順逆行分開設定。確認後更新結果；取消不套用草稿。使用原本的儲存專案功能保存到 Schema 8 檔案，載入時保留設定。舊存檔未配置時顯示未配置。

## 兩種基準

- 手冊方向：新設定預設；中間站離站加速度使用離站坡度，進站煞車減速度使用進站坡度。
- URCS相容：保留既有相反坡度來源，供比對歷史結果。模式隨設定保存並顯示在結果中。

兩模式目前只切換中間站坡度來源，其餘公式沿用現有模型。「手冊方向」名稱不代表每一個號誌或折返情境均經手冊逐項認證。

坡度單位為‰，以列車行駛方向為準：正值上坡、負值下坡。如果原始資料沿固定里程方向定義坡度，必須先換算成各行駛方向；程式不會自動反號。加減速度是未套用坡度修正的基準值，避免重複修正。

## 輸出定義

- 安全時距 Ts：各設施公式算出的最小追蹤時間，秒。
- 設計班距 h：Ts乘以1加營運餘裕率，秒。
- 列車容量：3600/h向零截斷，列／小時。
- 設計旅客容量：列數乘以列車乘位，再截斷，乘位／小時。
- 可達成旅客容量：設計容量乘PHF後截斷，人／小時。

PHF不改變列數或班距。保留小數班距供檢查，不先把班距四捨五入後再算列數。兩模式均使用既有截斷規則。

結果不直接代表整線最大容量；分支、共用資源、快慢車、路徑與營運安排仍需模擬或另立容量情境。容量設定預設只供分析，不會自動改變SimulationWorld。按「套用中間站參數至運行」才明確建立實體坡度、速限、車型煞車、方向別停站與閉塞保護；候選設定完整驗證後才替換運行。

## 依據與已知差異

- [運研所2019年臺灣鐵道容量手冊](https://www.iot.gov.tw/zh_tw/archive/pub/softwareapp/?wiki=59444913)：都會篇表4.1、4.2及中間站推導。
- [TRB TCRP Report13](https://onlinepubs.trb.org/onlinepubs/tcrp/tcrp_rpt_13-b.pdf)：§3.7.1、3.7.3–3.7.4。
- [TRB TCRP Report165第三版](https://onlinepubs.trb.org/onlinepubs/tcrp/tcrp_rpt_165ch-03.pdf)：頁3-33。
- [ERA Introduction to ETCS Braking Curves](https://www.era.europa.eu/system/files/2022-11/Introduction%20to%20ETCS%20braking%20curves.pdf)：§3.3.1、頁12。

國外文獻支持坡度效應及所在区段的原則，其模型不等同本程式。2026-10-13的URCS介面驗算15組、60項輸出與相容公式一致；進站+10‰、離站−10‰時，相容h約130.468秒，手冊方向約119.983秒。差異原因沒有作者說明，不能直接確定為URCS內部程式錯誤。

## 同情境瓶頸與敏感度

在編輯器勾選「這些參考點屬同一容量分析情境，顯示瓶頸」後，結果頁顯示兩方向最長班距的參考點。只對自己確認可共同比較的點啟用；預設不將所有獨立參考點合併。

「敏感度分析」可選銜接點的主線連續通過比例，或折返點的停靠時間。輸入起點、终點、正步長及選填目標班距，結果最多201筆；未能整除終點時不另補一筆不規則步長。其它設定與所選模式固定，掃描不會修改原專案。目標判斷使用未四捨五入的h。

[手冊8例與4個對照／改善分支](../samples/handbook-capacity/README.md)可用於操作與核對，來源數值及補充假設見各案驗證紀錄。

## 套用至實際運行（2026-10-15）

容量頁的「套用中間站參數至運行」要求參考點StationId明確對應既有實體車站；不依名稱、畫面或里程猜測。它會保留現有拓樸幾何，產生可保存的SignalBlocks、軌道坡度／速限與方向別停站模式，套用車長、牽引及BrakeEffect對營運煞車的影響。較低的既有實體速限仍生效。坡度衝突、缺站或保護距離不足時拒絕候選，不先污染目前專案。

保護區延伸至停車位置＋出站號誌距離＋overlap，前車車尾淨空後再等待反應時間；合成入口設在停止列車上游車尾位置，是明列模型假設。坡度以車頭單質點計算，制動採前方最不利坡道，尚非現地號誌／全車長坡度模型。PHF、旅客容量及營運餘裕仍是分析／需求值，不用公式Ts直接節流列車。

折返案例由實體幾何builder另行建立15/30/20m間距、渡線與對稱尾軌，並載入同一SimulationWorld；按鈕不會自動搬動任意專案的實體折返設施。新的11小時、中央10小時比較方法及重跑命令見 `scripts/CapacityThroughputExperiment/README.md`。前後積壓或延誤成長時，不得將平均通過量稱為可持續容量。
