# V4.1.1

本版以v4.1.0為基準，新增多營運路線與逐站班表、容量分析及實測比較、範例整理與軟體內更新。

- 可建立多條營運路線、主支線及保守單線情境，並指定每站表定發車與最低停站時間；路線識別沿用同一個SimulationWorld結果資料流。
- 容量頁支援五類參考點、方向與坡度參數、分類圖表、瓶頸、整數／三位小數，以及同一模擬快照的理論／實測比較。
- 實體坡度、可選閉塞與overlap進入動態模擬；修正折返後道岔保護與低速精停附近堵車，配線圖水平主線改為等實體距離映射。
- 15份維護路線範例分入小型／中型／大型，另含12份手冊容量案例，總計27份可載入專案；路徑及索引同步更新。
- 新增「檔案 → 更新中心」：程式／資料分通道、可選啟動檢查、下載驗證、外部更新器、備份／復原與更新前專案副本。此版沒有即時推播或差分OTA。

Windows x64完整包附帶.NET 10執行環境，完整解壓縮後執行根目錄「MRT路線進出站時間模擬器.exe」。請保留updater、mcp、samples及授權目錄。舊版缺少安裝receipt時，先將完整新包解壓至新的普通資料夾，之後才能使用程式內更新；Git工作目錄禁止自我更新。

Schema仍為8；請使用新版編輯含新設定的專案。單線、號誌、坡度與容量均為概念模型，範例未知參數仍屬示範假設。平均列車通過量不是正式安全容量或實際旅客吞吐量；原生DPI及實體操作驗收界線見QA_REPORT.md。

下載前可用SHA256SUMS.txt核對完整ZIP及更新套件。程式更新資產位於本Release，範例資料位於data-v1.0.0；只更新程式碼提交不會觸發客戶端通知。
