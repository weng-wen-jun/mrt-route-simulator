# 範例資料 v1.0.0

提供V4.1.1更新中心的第一版範例資料通道，包含27份Schema 8可載入專案：15份小型／中型／大型維護路線範例與12份手冊容量案例，以及對應README。

資料更新僅切換受管理範例庫，不覆蓋使用者存檔或目前模擬。下載後會驗證manifest、套件及逐檔SHA-256與大小，並由Engine驗證全部專案後才切換版本。

這些是概念模型與回歸情境，包含明確示範假設，不能作為正式工程設計或安全認證容量。完整Windows程式請使用v4.1.1程式Release；本資料Release不設為GitHub最新程式版本。
