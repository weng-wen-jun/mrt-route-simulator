# 容量圖表與實測比較

入口：結果 → 容量參考點 → **容量圖表與比較…**。先在「編輯容量設定」配置參考點；需要紅色瓶頸線時，須明確啟用同一容量情境比較。

## 結果內容

- 結果表：設計班距、理論列車容量、設計乘位、可達成容量、實測事件數／列車流率與差值。
- 路線容量：各點整數截斷容量長條圖；中間站藍、站前折返橙、站後折返紫、中央避車線綠、銜接點黃。
- 設計容量與可達成容量：分別顯示理論乘位／小時、含尖峰小時因子的理論人／小時。
- 理論與實測：理論用未截斷 `3600 / design headway`，綠柱為所選窗口實測事件數除以窗口小時數。旅客吞吐量未模擬。

上方「路線容量顯示」可切換「整數截斷（手冊）」與「未截斷（3位小數）」。未截斷用Engine設計班距的3600/h，柱高與瓶頸線使用未四捨五入數值，表格／標籤顯示3位小數；CSV保留顯示模式。設計／可達成旅客容量維持Engine原結果；理論實測比較固定使用未截斷值，數值標籤亦顯示3位小數。

順／逆行選擇同時更新表、圖與瓶頸摘要。中間站有方向別設定，其餘設施沿用單組幾何，不表示建立獨立反向模型。

## 實測資料與窗口

實測來自目前主視窗單一播放 worker 的 immutable PlaybackFrame，開啟視窗或按「更新實測快照」取得一份固定快照，不另建或推進 SimulationWorld。統計不因播放倍率跳過事件。

起訖欄位為相對模擬起點的分鐘，採 `[start, end)` 半開窗口。11 小時預設鈕設定 `[30,630)` 分鐘；12 小時預設鈕設定 `[90,690)` 分鐘，都是10小時。這些按鈕只設定窗口，不啟動長時間模擬。窗口終點超過快照時間時顯示缺值，不能拿尚未跑完的資料除以完整10小時。

只依參考點的明確 StationId 與方向篩選，車次按 ServiceRunId 去重；缺少車次ID的事件忽略並提示。ID識別與topology一致，不區分大小寫。終點折返的同方向離站可能為0，請明確選「到站事件」查看抵達量；不自動交換兩種事件。

未模擬、無效窗口、未對應實體站的結果顯示「—」。合法已完成窗口內沒有事件才顯示0。銜接點需獨立實體通過事件，不能把附近車站離站量當作銜接點容量，因此目前該類點的實測欄位明確標示未對應。理論與運行條件是否等同仍需確認；有通過量不代表找到最大容量或通過安全驗證。

## 儲存與複製

結果表可儲存CSV或複製文字；CSV包含方向、量測窗口、事件種類、快照時間與理論模式。圖表可儲存PNG／PDF或複製圖片，匯出包含圖例、方向、單位與瓶頸註記。多個參考點可水平捲動，輸出保留整個圖表。

## 維護

`CapacityResultsWindow` 只消費 SpatialCapacityAnalysis／SpatialCapacityScenarioAnalysis 的結果；觀測流率由 Engine 的 CapacityObservationAnalysis 聚合，不重新模擬。Schema未變，物理與派車控制未變。加入回歸涵蓋半開窗口、站／方向、去重、無效及空窗口、非均勻班距中位數、圖表方向與柱高、瓶頸線、缺值／零值、實測切換及PNG/PDF/CSV。
