# V4.1.1 與 V4.1.0 差異

整理日期：2026-10-16。比較基準為正式發布的 v4.1.0；本輪依使用者指定將整合版本定為 V4.1.1。來源版本由 Directory.Build.props 管理。本輪包含原始碼、[v4.1.1程式Release](https://github.com/weng-wen-jun/mrt-route-simulator/releases/tag/v4.1.1)與[data-v1.0.0範例資料Release](https://github.com/weng-wen-jun/mrt-route-simulator/releases/tag/data-v1.0.0)。

| 項目 | V4.1.0 | V4.1.1 |
|---|---|---|
| 營運路網 | 既有 topology、服務路徑及雙向派車 | 可編輯多營運路線、單／雙線、主支線及明確接軌位置，班次指定 ServiceRoute |
| 逐站班表 | 既有派車與停站模式 | 每站表定發車與最低停站秒數；晚到仍須停滿，安全與資源條件持續約束離站 |
| 結果識別 | 既有車次與方向資料 | 快照、事件、時刻表、軌跡及區間結果保留營運路徑／路線識別，支援路線別比較與CSV |
| 配線圖 | 已翻新的方向色、占用亮燈及列車標記 | 可調整並保存垂直配置；修正水平主線等距映射及重複繪製節流 |
| 容量分析 | 尚無本輪容量參考點子系統 | 五類參考點、方向別／坡度參數、手冊方向與URCS相容模式、理論容量及瓶頸 |
| 容量結果 | 既有模擬結果與輸出 | 表格與長條圖、順逆行、三位小數、同情境瓶頸線、同一快照的理論／實測比較及CSV/PNG/PDF |
| 動態模擬 | 既有移動閉塞與實體設施 | 實體坡度牽引／制動、可選閉塞及overlap、車尾淨空轉換、中間站容量參數明確套用 |
| 修正 | 既有turnback／passing保護 | 補強換端後前方道岔保護，修正低速精停附近永久堵車，保持資源與安全約束 |
| 範例 | 14份維護路線範例 | 15份維護範例分為小型12／中型2／大型1，另有12份手冊容量案例；各類獨立編號 |
| 更新 | 手動取得完整發布包 | 程式／資料兩通道、可選啟動檢查、雜湊與大小驗證、外部更新器、備份復原及專案副本 |

## 格式與相容性

- 現行可編輯／保存格式維持 Schema 8，舊版新增欄位省略時使用相容預設。合法Schema 7仍走既有匯入轉換；不新增另一套runtime。
- 新的營運路線、逐站班表、坡度、閉塞與容量設定應使用V4.1.1編輯；不要用舊程式重新儲存含新欄位的專案。
- 固定0.1秒SimulationWorld步進仍為正式物理來源；圖表與觀測不另跑一套模擬。
- 舊範例路徑改為分類子資料夾，外部腳本請參照 [範例索引](../samples/README.md) 更新。GitHub main只保留新路徑，舊路徑仍可由歷史提交查閱。

## 驗證與限制

Release build 0警告／0錯誤、Engine 238/238、更新核心67/67、更新器17/17、更新中心14/14、完整WPF回歸通過。27份實際專案均可反序列化並建立runtime；候選包已驗證4.1.0→4.1.1 receipt升級並保留自訂檔，正式自含包再以發布驗收核對完整檔案及授權。細節與歷次證據見 [QA_REPORT.md](../QA_REPORT.md)。

手冊驗證另有38輪局部／整線實驗。局部以11小時、扣前後各半小時觀測中央10小時；整線依暖機需要使用12小時、前90分鐘及末30分鐘不計。這是給定需求下的平均通過量與可行性研究，不是對所有情境搜尋最密班距或證明整線可持續最大容量。部分整線情境仍有預測安全狀態事件，未一律列為零預警通過。

單線採保守整線互斥，尚無自動會車最佳化。範例幾何與未知工程參數為示範假設，旅客擁擠、曲線阻力、黏著變化與正式路線校準未完成。離屏WPF及自動化測試不代表原生Windows DPI、實體滑鼠、compositor或鐵路安全認證。

更新中心只在手動操作或啟動時查詢，不是GitHub即時推播；不自動下載／安裝。程式採完整套件，尚無差分OTA或獨立簽章。公開Release仍須提供相容manifest與ZIP，才有可下載內容。詳見 [更新說明](UPDATES.md)。
