# 大型機場線示範範例參考

> 這份文件只描述去識別化後的 synthetic topology scenario，未保留原始路線名稱、城市名稱、站名或外部文件識別資訊。

## 用途

本文件供大型 Schema 8 sample、Scenario Builder、regression tests 與後續維護使用。它是程式測試的情境契約，不是正式路線、工程配線、號誌設計或營運時刻表。

## 情境與資料界線

- 路線採 28 站的抽象站鏈，站號使用 `O01`～`O26`，另含兩個支援測試的插入站 `O08a`、`O15a`。
- 全程服務使用 `FULL-LINE`，區間服務使用 `SECTION`，機場端快車使用 `AIRPORT-DIRECT`；這些名稱是通用測試識別，不指向任何現實營運單位。
- `O20` 為中段／端點袋式儲車軌折返位置；`O04` 與 `O13` 為雙向 passing／待避測試位置。
- 29.9 km、23.8 km、逐站距離、月台與車體尺寸、性能、停站、設施幾何、速限、port side 及派車 offset 全部視為 synthetic test values。它們只用來固定 regression 結果，不是外部來源的精確重建。

## 驗證情境

1. 先完成 minimal topology，再依序建立 station chain、service patterns、turnback、兩處 passing 與 timetable。
2. 驗證全程車完成 28 站、快車依停站模式 skip-stop、區間車在 `O20` 折返，以及 `O04`／`O13` 越行時的 rear-clear 與 resource release。
3. 以 Schema 8 round-trip、topology-native `SimulationWorld`、無碰撞／無停站違規及 8,000 秒有界執行作為 regression gate。

## 明確不涵蓋

- 正式城市／路線／車站名稱、正式逐站里程、平縱面、曲線與坡度。
- 正式車輛、號誌、閉塞、容量、班表、轉乘與工程設計參數。
- 任何可由本文件反推出原始路線身分的外部來源或照片。

通過測試只證明去識別化 synthetic topology 可執行，不能推論任何現實路線的設計、能力或安全性。
