# Security Policy

## Reporting a vulnerability

Please report suspected cybersecurity vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/weng-wen-jun/mrt-route-simulator/security/advisories/new).
Do not post exploit details, credentials, personal information, or confidential railway data in public issues.

Include the affected version or commit, a minimal synthetic reproduction, expected impact,
and relevant sanitized logs. Do not test against systems you do not own or have permission to test.
The maintainer will assess reports; no fixed response time or long-term support period is promised.

This conceptual simulator is not a certified or deployable railway safety system.
Model accuracy, timetable assumptions, and ordinary UI bugs belong in public issues when
they do not expose a cybersecurity vulnerability or sensitive information.

## 私人回報

疑似資安漏洞請使用上述 GitHub 私人漏洞回報入口，不要在公開 issue 張貼利用細節、
登入憑證、個資或機密營運資料。請附版本／commit、最小合成重現案例、可能影響與去識別化紀錄。
本專案不承諾固定回覆時間或長期版本維護；一般模型精度、營運假設或 UI 問題可透過公開 issue 回報。
